## Flow ของแอป

```
Splash (โลโก้ พื้นขาว, ครั้งเดียวต่อ session, แตะข้ามได้)
   ↓

             → เลือกจุดหมาย → แนะนำ → ทริปของคุณ
   ↓
หน้าจุดหมาย   รูปใหญ่ + ไทล์หมวด + แถวเลื่อนรายหมวด + [เริ่มจัดทริป]

```

## ฟีเจอร์

### จัดทริป
- หลายทริปพร้อมกัน แต่ละทริปผูกกับจุดหมาย
- ไทม์ไลน์รายวัน แก้เวลาแล้วเรียงใหม่อัตโนมัติ
- **เลือกที่ทีละหลายอัน** พร้อมไล่เวลาให้ตามลำดับที่ติ๊ก
- **บอกระยะห่างจากจุดก่อนหน้า** — จุดอ้างอิงขยับตามที่ติ๊กล่าสุด มีปุ่มเรียงตามระยะ
- ระยะห่างระหว่างจุดในไทม์ไลน์ (Haversine จากพิกัดจริง)

### นำทาง
- **รายจุด** → `maps/dir/?api=1&destination=` ใช้พิกัดถ้ามี ไม่งั้นใช้คำค้น
- **ทั้งวัน** → เส้นทางเดียวจากจุดแรกถึงจุดสุดท้าย ใส่จุดกลางเป็น waypoints (สูงสุด 9)

### เพิ่มสถานที่เอง (3 ขั้น)
1. พิมพ์ชื่อ → กด **ค้นหาบน Google Maps** (เปิดแท็บใหม่)
2. ก๊อปลิงก์กลับมาวาง → แอปแกะ **ชื่อ + พิกัด** ให้อัตโนมัติ
3. เลือกหมวด → บันทึก

รองรับลิงก์ 4 แบบ: `/maps/place/ชื่อ/@.../!3d..!4d..` · `/@lat,lng,17z` · `?query=ชื่อ` · `?query=lat,lng`
**ลิงก์ย่อ `maps.app.goo.gl` แกะไม่ได้** (ต้องยิง network ซึ่ง CSP บล็อก) — ส่งมาให้ผมแกะให้ได้

### อื่น ๆ
- **รูป** — กดที่รูปเพื่ออัปโหลดจากเครื่อง (ย่อ 620px, เก็บใน localStorage) มีหน้าจัดการรูปใส่รวดเดียวหลายที่ + ลากไฟล์วางได้
- **คำบรรยาย** — แก้ได้ทุกที่ ลำดับ: ที่คุณเขียน → ตั้งต้น → API → โน้ตสั้น
- **ปักหมุด** — ที่ที่ปักไว้ขึ้นแถวแรกของหน้าค้นหา
- **Responsive** — มือถือ / แท็บเล็ต 600px / เดสก์ท็อป sidebar สูงสุด **1440px** (แผนทริปเป็น 2 คอลัมน์)
- **Dark mode** ตามระบบ + ปุ่มสลับเอง

## ข้อจำกัดของ Artifact (CSP)

หน้าที่ publish บน claude.ai บล็อก:

- ❌ **รูปจากโดเมนภายนอก** — ต้องฝังเป็น data URI เท่านั้น
- ❌ **`maps.googleapis.com`** — Maps JS API / Places Autocomplete โหลดไม่ได้
- ❌ **iframe ไปเว็บนอก** — ฝัง Google Maps ไม่ได้
- ❌ **fetch / XHR ออกนอกโดเมน** — ตามลิงก์ย่อไม่ได้

**ผลคือ** ทุกอย่างต้องเตรียมตอน build แล้วฝังลงไฟล์ · ถ้าอยากได้ Maps จริงในแอป ต้องย้ายออกจาก Artifact ไปเปิดเป็นไฟล์ในเครื่องหรือโฮสต์เอง

## โครงข้อมูล

```js
place = {
  id, dest, cat,          // cat: dimsum|restaurant|dessert|cafe|spot|beach|island|stay
  name, note, q,          // q = คำค้นสำหรับ Google Maps
  lat, lng,               // ถ้ามี → ปุ่มนำทางแม่นยำ + คำนวณระยะได้
  img, desc               // ที่ผู้ใช้ใส่เอง เก็บใน localStorage
}

trip = { id, name, dest, startDate, days:[ {id, label, items:[{pid, time, note}]} ] }
```

**บล็อกข้อมูลที่สคริปต์เขียนลงไป** (คั่นด้วย marker ห้ามลบ)

| Marker | เนื้อหา |
|---|---|
| `/* TAT_START */ … /* TAT_END */` | `TAT_META` `TAT_PHOTOS` `TAT_CREDITS` |
| `/* LOCALPHOTOS_START */ … /* LOCALPHOTOS_END */` | `LOCAL_PHOTOS` `LOCAL_CREDITS` |
| `/* PHOTOS_START */ … /* PHOTOS_END */` | `PHOTOS` `PHOTO_CREDITS` `PLACE_META` (Google) |

**ลำดับความสำคัญ** — รูป: ที่อัปโหลดเอง → Google → TAT/Wikidata → ชุด local · คำบรรยาย: ที่เขียนเอง → ตั้งต้น → API → โน้ต

**จุดหมายเปิดอัตโนมัติ** — `isSoon(d) = destPlaces(d.id).length === 0` เพิ่มสถานที่เข้าไปแล้วจังหวัดเปิดเอง ไม่ต้องแก้โค้ด

### การเติมพิกัด (ทำแล้ว — ไม่ใช้ API key)

พบว่า `https://www.google.com/maps?q=<ชื่อ>&output=embed` คืนหน้า HTML เล็ก ~3.7 KB
ที่มีพิกัดที่ Google resolve ให้แล้วอยู่ในนั้น **ไม่ต้องใช้ key ไม่ต้องเปิด billing**
เรียกจากคอนโซลของแท็บ `google.com` (same-origin) แล้วดึงด้วย regex

```js
const geo = async q => {
  const r = await fetch('/maps?q=' + encodeURIComponent(q) + '&output=embed');
  const t = await r.text();
  const m = t.match(/(?<![\d.])([78]\.\d{4,}),(9[78]\.\d{4,})(?![\d])/);
  return m ? [+m[1], +m[2]] : null;
};
```

**ตรวจความแม่นแล้ว** เทียบกับ 6 ที่ที่รู้พิกัดอยู่ก่อน — คลาด 0–32 ม. 4 ที่,
แหลมพรหมเทพคลาด 270 ม. (เป็นแหลมใหญ่ Google ปักกลางพื้นที่)

**ข้อควรระวัง** — regex ต้องมี boundary `(?<![\d.])` กันไปจับตัวเลขอื่นที่ซ้อนอยู่ในหน้า
ตอนแรกใช้แพตเทิร์นกว้างเกินแล้วได้ latitude เพี้ยนเป็น 50–76 ทั้งชุด

**2 ที่ที่พิกัดซ้ำกับที่อื่นโดยตั้งใจ**

| | ทับกับ | เหตุผล |
|---|---|---|
| `p7` จุดชมวิวสามอ่าว | `p4` จุดชมวิวกะรน | เป็นที่เดียวกัน คนละชื่อเรียก — Google ไม่รู้จักชื่อ "สามอ่าว" |
| `p8` ถนนคนเดินหลาดใหญ่ | `p9` ถนนถลาง | ตลาดตั้งบนถนนถลาง ค้นชื่อตลาดตรง ๆ ไม่เจอ เลยใช้พิกัดถนน |

ถ้าอยากได้แม่นกว่านี้เป็นรายที่ ใช้ปุ่ม **"เพิ่มสถานที่"** ในแอปวางลิงก์ Google Maps ทับได้

## ข้อควรรู้

- **ข้อมูลอยู่ใน localStorage ของเบราว์เซอร์เครื่องนั้น** ไม่ sync ข้ามเครื่อง เปิดจากมือถือจะเป็นข้อมูลตั้งต้น
- **พื้นที่ ~5 MB** ใส่รูปเองได้ราว 60-80 รูป เต็มแล้วแอปจะเตือนและไม่บันทึกทับ
- **ลิขสิทธิ์รูป** — รูปจากเว็บรีวิว (Wongnai ฯลฯ) ใช้ส่วนตัวได้ แต่ถ้าจะแชร์ลิงก์สาธารณะหรือทำเป็นโปรดักต์ ควรเปลี่ยนไปใช้ Google Places ซึ่งให้สิทธิ์ใช้ในแอปพร้อมเครดิต
- **โฟลเดอร์นี้ยังไม่อยู่ใน git** — แนะนำให้ `git init` เพราะระหว่างพัฒนาเคยทำไฟล์พังจนต้องกู้จาก Artifact มาแล้ว
